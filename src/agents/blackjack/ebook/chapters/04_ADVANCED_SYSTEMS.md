# Chapter 4: Advanced Counting Systems

## When Hi-Lo Isn't Enough

Hi-Lo is the Toyota Camry of counting systems. Reliable, gets the job done, works for 95% of people.

But some players want more precision. They're willing to put in extra practice for marginal gains.

This chapter covers two advanced systems:
- **Omega II** — The balanced powerhouse
- **Wong Halves** — Maximum accuracy

**Important**: Master Hi-Lo first. These systems are harder and the edge gain is small. Don't run before you can walk.

---

## Omega II System

Omega II is a "Level 2" system, meaning some cards have values of +2 or -2 instead of just +1/-1.

### Card Values

| Cards | Value |
|-------|-------|
| 2, 3, 7 | +1 |
| 4, 5, 6 | +2 |
| 8, A | 0 |
| 9 | -1 |
| 10, J, Q, K | -2 |

### Why Omega II?

More granular values = more accurate count.

The key insight: 4, 5, 6 are the **most important** low cards (they hurt you the most), so they get +2. Meanwhile, Aces are tracked separately because they're both high AND good for blackjacks.

### Ace Side Count

Omega II doesn't include Aces in the main count. Instead, keep a separate count of Aces seen.

In a 6-deck shoe, there are 24 Aces. At any point:

- If fewer Aces seen than expected → Ace-rich shoe → Good for player
- If more Aces seen than expected → Ace-poor shoe → Slightly worse

**Expected Aces formula**: (Decks dealt × 4)

Example: 3 decks dealt. Expected Aces seen: 12. If only 7 seen, the remaining shoe is Ace-rich.

### Difficulty Level: 7/10

The +2/-2 values make mental math harder. The ace side count adds cognitive load. Only use Omega II if Hi-Lo feels too easy.

## Wong Halves System

Wong Halves is arguably the most accurate counting system ever developed. It uses fractional values.

### Card Values

| Cards | Value |
|-------|-------|
| 3, 4, 6 | +1 |
| 2, 7 | +0.5 |
| 5 | +1.5 |
| 8 | 0 |
| 9 | -0.5 |
| 10, J, Q, K, A | -1 |

### The Fraction Problem

Counting by halves is mentally taxing. Most players use the **doubled system**:

| Cards | Doubled Value |
|-------|---------------|
| 3, 4, 6 | +2 |
| 2, 7 | +1 |
| 5 | +3 |
| 8 | 0 |
| 9 | -1 |
| 10, J, Q, K, A | -2 |

Then divide by 2 at the end to get the true count.

### When to Use Wong Halves

Honestly? Almost never.

The accuracy improvement over Hi-Lo is ~0.1% edge. That's real money over tens of thousands of hands, but the mental strain and increased error rate often cancel out the gains.

Wong Halves is for:
- Professional players betting high stakes
- Math enthusiasts who want maximum precision
- People with exceptional mental arithmetic

For everyone else: Hi-Lo or Omega II is plenty.

## System Comparison

| System | Level | Accuracy | Difficulty | Edge Improvement Over Hi-Lo |
|--------|-------|----------|------------|---------------------------|
| Hi-Lo | 1 | Good | Easy | Baseline |
| Omega II | 2 | Very Good | Medium | +0.05% |
| Wong Halves | 3 | Excellent | Hard | +0.1% |

**The reality**: A well-executed Hi-Lo system beats a poorly-executed Omega II every time. Consistency matters more than system complexity.

---

## Which System Should You Choose?

**Choose Hi-Lo if:**
- You're starting out
- You play in noisy/distracting environments
- You want a good edge with minimal mental load
- You play casually (under 20 hours/month)

**Choose Omega II if:**
- You've mastered Hi-Lo completely
- You play seriously (50+ hours/month)
- You can handle the ace side count
- You're playing for profit, not recreation

**Choose Wong Halves if:**
- You're a professional-level player
- You bet very high stakes
- You've mastered Omega II
- You genuinely enjoy the mental challenge

## Key Takeaways

✅ Hi-Lo is sufficient for 95% of advantage players
✅ Omega II adds accuracy with +2/-2 values and ace side count
✅ Wong Halves is maximum precision but very difficult
✅ Consistency beats complexity — master your system before upgrading
✅ Edge gains from advanced systems are marginal (~0.05-0.1%)
